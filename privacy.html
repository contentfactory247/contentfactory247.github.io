Privacy Policy

ChapterEk Uploader · last updated 21 November 2026

ChapterEk Uploader is a private tool used only by the ChapterEk team to publish ChapterEk's own videos to ChapterEk's own YouTube channel. This page explains how it handles Google user data.

What Google data it accesses

With the channel owner's permission (Google OAuth), it uses the YouTube Data API to upload videos and thumbnails to the ChapterEk channel (youtube.upload) and to read the channel's name (youtube.readonly). It does not access any other Google account, and it does not read email, contacts, files or viewer data.

How the data is used

Only to upload and schedule ChapterEk's own videos and to confirm the channel is connected. Nothing is used for advertising, profiling or any other purpose.

Storage

The tool stores one item: the OAuth sign-in token for the ChapterEk account, kept encrypted on the team's private server so uploads can run on schedule. No other Google user data is stored.

Sharing

Google user data is never sold, shared with or transferred to anyone. Videos are published on YouTube only as the channel owner chooses.

Limited Use

ChapterEk Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Its use of YouTube is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Removing access

The channel owner can remove the tool's access at any time at myaccount.google.com/permissions; the stored token then stops working and is deleted.
