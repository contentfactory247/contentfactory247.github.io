Privacy Policy

ChapterEk Uploader · last updated 24 November 2026

ChapterEk Uploader is a private tool used only by the ChapterEk channel owner to publish ChapterEk's own videos to ChapterEk's own YouTube channel. This page explains how it handles Google and YouTube user data.

YouTube API Services

ChapterEk Uploader uses YouTube API Services (the YouTube Data API v3). By using ChapterEk Uploader you agree to be bound by the YouTube Terms of Service. How Google handles data is described in the Google Privacy Policy.

What data it accesses

With the channel owner's permission (Google OAuth), it uploads videos and thumbnails to the ChapterEk channel (youtube.upload) and reads the channel's name and ID to confirm the connection (youtube.readonly). It does not access any other Google account, and it does not read email, contacts, files, comments, analytics or viewer data.

How the data is used

Only to upload and schedule ChapterEk's own videos and to confirm the channel is connected. Nothing is used for advertising, profiling or any other purpose.

What is stored

The tool stores one item: the OAuth refresh token for the ChapterEk account, kept encrypted (AWS Systems Manager Parameter Store, SecureString) on the team's private server so uploads can run on schedule. The channel name returned by the API is shown once to confirm the connection and is not stored. No other Google or YouTube user data is stored.

Sharing

Google and YouTube user data is never sold, shared with or transferred to anyone. Videos are published on YouTube only as the channel owner chooses.

Cookies

This website and the tool do not use cookies or tracking, and do not store anything on your device.

Revoking access and deleting data

  • Revoke: the account owner can remove the tool's access at any time in Google's security settings at myaccount.google.com/permissions. The stored token then stops working.
  • Deletion: when access is revoked or the tool is retired, the stored token is deleted from the server within 7 days. You can also ask for deletion at any time through the contact below; we delete the token and confirm within 7 days.
  • Retention: the token is kept only while the tool is in use.

Limited Use

ChapterEk Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If this policy changes, the new version is posted on this page with a new date.
